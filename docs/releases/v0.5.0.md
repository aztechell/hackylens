# HackyLens 0.5.0

This release supports HUSKYLENS SEN0305 and Sipeed Maix Cube with all twelve
applications and embedded MicroPython.

## Changes

- Maix Cube hardware support: 240x240 display with DMA, two-page launcher,
  OV7740 camera, SD, RGB/illumination and saved settings. POW acts as BACK;
  POWER provides SLEEP, POWER OFF and RESTART.
- Correct RGB model input and mounting rotation on Cube. Detection boxes map
  back to the displayed camera image. FACE detection was confirmed on a face.
- QR releases its workspaces on exit, fixing OBJECT model allocation after QR.
  The supplied VOC20 model loads and completes inference on Cube.
- Camera register transport is selected independently from the sensor driver.
  Board contracts specify seven-bit addresses and SCCB/I2C timing explicitly;
  register operations have bounded deadlines and preserve read errors.
- DVP capture uses a neutral input format and no longer selects sensor models.
  Existing application APIs, settings and flash partitions are preserved.
- Short flash SPI transfers are protected from AI interrupts and bounded by
  deadlines, fixing MicroPython uploads while FACE is running.
- The Cube PMIC bus recovers from a held SDA after reset. POW/BACK setup retries
  without changing rail voltages or charging settings.

## Downloads

Choose the ZIP matching your board:

- `hackylens-huskylens-sen0305-v0.5.0.zip`
- `hackylens-sipeed-maix-cube-v0.5.0.zip`

Each archive includes the firmware, matching flash metadata, SD-card models,
build attestation, notices and internal checksums. `SHA256SUMS.txt` verifies the
two downloads. Extract the package and copy the contents of its SD-card archive
to the root of a FAT32 card. Flash the matching `.bin` with the same board
profile and paired `.json`; firmware programming preserves settings and userfs.

## Validation

Both board builds, reduced compositions, host tests and architecture checks
pass. Physical checks cover cold startup, camera sizes, colorbar, probe/reinit
and application switching on both boards. Cube FACE recognition and OBJECT
model loading/inference were checked after the AI fixes.
MicroPython upload/read/run/STOP and file cleanup also passed directly from
active FACE. POW/BACK was physically confirmed after PMIC bus recovery.

External UART/I2C remain supported. Physical exchange with an external fixture
was skipped by the maintainer's decision and is not claimed as a hardware test.
