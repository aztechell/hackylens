# HackyLens 0.6.0

This release ships twelve apps on HUSKYLENS SEN0305 and fourteen on Sipeed
Maix Cube. Both include embedded MicroPython.

## Changes

- Cube RECORDER captures 16-bit mono PCM at 15,869 Hz to numbered WAV files on
  FAT32 microSD. RECORDER and FILES share a player for 16-bit mono and stereo
  PCM WAV from 8 to 48 kHz.
- RECORDER, FILES and MicroPython share the Cube speaker volume. Existing
  settings load with the previous speaker level as the default. The volume
  is saved alongside the other settings.
- Cube ACCELEROMETER shows live X/Y/Z readings from the MSA301. Native apps
  and `hackylens.acceleration_mg()` use the same typed binding. MicroPython
  also exposes short PCM capture and playback on Cube.
- `hackylens.display_rects()` batches filled rectangles for animated graphics.
  Native App SDK 0.3.0 adds a panel helper and an accelerometer accessor.
- SD reads retry at a lower SPI clock after a transport error. Directory
  scans distinguish end of chain from an unreadable or cyclic FAT chain.

## Downloads

- `hackylens-huskylens-sen0305-v0.6.0.zip`
- `hackylens-sipeed-maix-cube-v0.6.0.zip`

Choose the archive for your board. Each includes firmware, the matching flash
metadata, an SD-card archive, build attestation, notices and checksums.
`SHA256SUMS.txt` verifies the downloads. Extract the SD-card archive to the root
of a FAT32 card. Flash the firmware with the matching board profile and paired
JSON to preserve settings and userfs.

## Validation

Release validation builds both full board profiles and the reduced SEN0305
compositions. It checks architecture boundaries, SDK and board conformance,
feature symbols, host behavior, the SEN0305 resource budget and release bundles.

During Cube development, RECORDER saved a 181-second WAV that played in both
RECORDER and FILES. FILES also played external 44.1 and 48 kHz stereo WAVs.
Playback restart, codec mute and volume persistence were exercised. The
accelerometer app displayed live samples and MicroPython read the same sensor.
The logged MicroPython sample window was stationary. See the
[Cube hardware log](../MAIX_CUBE.md) for the tested scenarios and
[v0.5.0 notes](v0.5.0.md) for the earlier board qualification.
