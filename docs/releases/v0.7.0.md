# HackyLens 0.7.0

This release ships thirteen apps on HUSKYLENS SEN0305 and fifteen on Sipeed
Maix Cube, including MicroPython and the new FACE RECOG app on both boards.

## Changes

- FACE RECOG enrolls up to ten local face IDs on a FAT32 card. Native apps,
  MicroPython, and the external link can read the published recognition
  results. See the [model setup and controls](https://github.com/aztechell/hackylens/blob/v0.7.0/docs/FACE_RECOGNITION.md).
- HackyLens Code can display a live USB preview and request a camera
  snapshot on either board. The firmware serves both through HMPY.
  The [web IDE](https://github.com/aztechell/hackylens-code) ships separately.
- CAMERA writes photos in larger FAT32 batches. FILES displays loading and
  format errors when opening images and keeps the selected entry on return.
  Launcher order and FILES icons have been updated.
- Maix Cube applies the screen brightness setting live using the adjusted
  backlight PWM.
- Camera buffers, PNG decode storage, and large model weights share one
  SRAM arena. OBJECT DETECT and FACE RECOG load their large weights without
  allocating a model-sized block from the system heap. Both VGA slots remain
  available to the normal camera preview.

## Downloads

- `hackylens-huskylens-sen0305-v0.7.0.zip`
- `hackylens-sipeed-maix-cube-v0.7.0.zip`

Verify your archive using `SHA256SUMS.txt`. Extract the firmware and its
matching JSON flasher sidecar together, then flash with the profile for your
board. Unpack the included SD-card archive and copy the contents of its
`sdcard/` folder to the root of a FAT32 card for FACE DETECT and OBJECT DETECT.
FACE RECOG also needs the two CanMV models
listed in the [setup guide](https://github.com/aztechell/hackylens/blob/v0.7.0/docs/FACE_RECOGNITION.md#install-the-models).

## Validation

Both boards loaded the VOC20 model and completed inference on seven launches
with six intervening unloads across FACE RECOG, CAMERA, QR-CAMERA, APRILTAG,
FILES, and MicroPython. Both returned to 640 × 480 in CAMERA and loaded the
three FACE RECOG models from microSD. Recognition enrollment and reload after
reset were exercised during development, including on live faces. See the
[recognition hardware checks](https://github.com/aztechell/hackylens/blob/v0.7.0/docs/FACE_RECOGNITION.md#hardware-verification).

Release CI checks host behavior, architecture, board and app composition,
full and reduced firmware profiles, and the integrity of both board archives.
The [v0.6.0 notes](https://github.com/aztechell/hackylens/releases/tag/v0.6.0) document the earlier Cube audio and motion checks.
